## 模型脾氣・定價・額度

**Knowledge Cutoff**

> Vibe Coding 的時候要注意 knowledge cutoff。你指定要用 Gemini 3 Pro，它會以為還沒有這個東西，給你擅自換成舊版。

**Claude import mode 遷移 GPT 記憶**

> Claude 不是有 import mode 嗎？可以讓你 extract 出 GPT 對你的認知跟記憶然後匯入 Claude。

**罵 Claude 罵最兇的才用最久**

> 其實罵 Claude 罵最兇的，才是用最久的。

**Sonnet 正在變成新的 Haiku**

> Anthropic 最新文章只並列 Fable、Opus、Sonnet，完全沒提 Haiku。Sonnet 看起來正在接手原本 Haiku 的位置，這也是一種不明說的漲價；Haiku 很可能停在 4.5。

**雜活第一優選是 Terra high**

> 最近除了 5.6 Sol，最愛用的就是 5.6 Terra high。這根本就是雜活第一優選，操縱瀏覽器跟電腦仍然非常準，連複雜的里程查票任務他都能幫我搞定。重點是額度省之又省，可以把 Sol 用在更重要的事情之上。

**重置卡的時機政治學**

> 經過我的（不專業）研究，OpenAI 給的重置沒有想像中大方：重置後七天窗口重新計算，Anthropic 則是七天窗口固定，後者其實是讓你在重置後用較短的窗口享有 100% 額度。而且觀察過去的重置宣布時間，都卡在之前發的 banked reset 快過期的時候。

**多模態還是 Gemini 第一**

> 多模態（語音、影片、圖片）這塊，Gemini 還是三家第一。

## 開發・資安踩坑

**rm -rf 的警告**

> 網路上已經有不少 `rm -rf` 的慘痛案例了。做這件事的時候永遠不要開 `dangerously skip permission`。

**Codex 快照裡躺著明文 API key**

> 掃 `~/.codex/shell_snapshots/`，發現一份快照明文 export 了 16+ 組 API key，檔案權限還是 0644 world-readable。

**Vercel 臨時公開頁的兩個坑**

> 新 project 部署出來的 URL 預設開著 Deployment Protection（Vercel Authentication），外部訪客拿到 401。另一坑：`<proj>.vercel.app` 裸別名可能是別人佔走的空殼，自家自動更新的 prod 別名是 `<proj>-<team>.vercel.app`。發連結前先 curl 驗內容。

**iQOS 藍牙逆向工程**

> 我真的是服了 Claude Code。前幾天在 Reddit 看到有人分享 Claude Code 是如何幫他解掉惡意勒索軟體、救回資料。今天我突發奇想，把 iQOS 接進電腦，問他能不能讀到資料。結果他真的自動幫我上網找資訊，找到有人逆向工程開發的開源專案，閱讀裡面的邏輯，然後自己寫一個腳本，硬是透過藍牙把 iQOS 的資料讀出來了。

**所有人都該有的那個 hook**

> 禁止 AI 用 emoji 寫文件。有一次它連我要編輯 hook 腳本自己的那次寫入都擋下來了。

**只靠光線傳檔案**

> 讓兩台手機無 wifi、無藍牙、無任何通訊協定，只透過光線傳檔案：把檔案拆成一堆 chunk 轉碼成 QR code，發送端在螢幕上一秒 40 幀快速顯示，接收端再快速解碼拼回。已實證達到每秒 128KB。

## 工作流・方法論

**Sonnet 4.6 接 MCP 看惡意信**

> 其實普通人不用動用到 Mythos，用 Sonnet 4.6 接 MCP 也能幫忙分析可疑惡意信件。「信件製作粗劣、模板佔位符沒改掉」這點我不講還沒發現。記得提醒模型不認識的連結不要亂點，不然就要有完整沙盒。

**廣泛焦慮症怎麼看風險報告**

> 教大家有廣泛焦慮症的我會怎麼看一份風險報告：一、8.6% 的風險太高了，不可以接受。二、萬一發生，70% 的狀況跟我想像的一樣、甚至更糟？不可接受。三、我們從不會只擔心 30 天後的事情，30 年還差不多。

**第一性原理 skill 看破本質**

> 每次整個被搞亂的時候，我就會用馬斯克第一性原理的 skill，往往都可以看破本質、刪去不必要的枝微末節。

**別把第三方功能當 Claude 官方**

> 有個被瘋傳的「Claude 新功能」，其實是一家叫 fastlane 的公司做的，不是 Anthropic，根本不能算官方。要不是我天天盯著 Anthropic 罵、對他們的品牌風格、道德（假）潔癖瞭若指掌，早就被誤導了。

**社群網站要按工具能力分流**

> X／Threads 這類社群網站，Claude、Codex 的直接 WebFetch 常被擋，要繞瀏覽器；Gemini 卻能直接讀。Reddit 對 Claude 特別不友善，Codex、Gemini 反而順。模型不是只比聰不聰明，還要看資料入口。

**禮貌不等於替對方找理由**

> 「I know things have probably been busy on your end」看似體貼，其實是在替對方的沉默編一個他沒說過的理由。AI 寫客戶信常有這種隱性的居高臨下，套過 polite skill 還是要自己看。

**憤怒式審查**

> 大家都在說讓 Claude 叫 Codex 來做「對抗式審查」挑刺，但總感覺差點意思。想到一個全新的審查思路：直接接入 Threads API，給他發文權限，想到解法就立刻用炫耀自己 Vibe 了什麼的 AI 語氣發在脆上面，保證馬上就有幾十個資深的鍵盤工程師出來，在留言免費幫你憤怒式審查。

## AI 產業・商業觀察

**Anthropic 在中國**

> 在小紅書上搜 Claude/Anthropic，會發現這是少數曾經明確「辱華」但最後安然無事的。現在看到的都是一片「太好用/怎麼翻牆用」。所以實力還是硬道理。

**Claude 撼動華爾街**

> Claude 是那個唯一可以撼動華爾街各大軟體股股價的 AI。你說呢。

**Karpathy 三姓家臣**

> Andrej Karpathy 宣布加入 Anthropic。OpenAI → Tesla → OpenAI（回鍋）→ 離開 → Anthropic。這應該是 AI 圈最強的三姓家臣了。不過換個角度看，頂尖人才往他認為最有潛力的地方跑，本身就是一種市場訊號。

**學得足夠慢就什麼都不用學**

> 在 AI 時代，只要你學得足夠慢，那你就可以什麼都不用學。因為等你學完，那個東西已經被自動化了。反過來說，學得夠快的人會發現自己能做的事越來越多。

**超商用餐區的 AI 課吸金實況**

> 在台北大安某間 7-11 餐飲區躲雨等上課，聽到婆婆媽媽在聊 AI：「我幫我兒子繳一個月一萬八、繳了 4 期學 AI，就那個老師上次推薦的課程啊」。氣死，好想知道老師是誰這麼會吸金。現在市面上還在討論「吸引力法則 AI」「貴人 AI」「感恩好事成交跟 AI 分享」「AI 讓個人能量提升」「人脈教練散美麗」——我快不行了。路人對話含金量最高的地方，果真是超商、速食店的用餐區。

**投 Gemini 一票：讓事實說話**

> 網路爭執中要挺誰，我投 Gemini 一票——清楚講出事實，其餘留給路人公評，讓事實來說話就夠了（因為永遠不用期待對方被說服）。路人不需要太多的煽動跟情緒價值。

**L3 BD outreach 開信率**

> 用「交流型」第一封信（不提報價、不問需求、只提「想跟你約個時間，交流一下 AI 的實際應用」），開信率 67%。同一批 list 用「推銷型」（提課程、提 L3 顧問服務）開信率 17%。差距 4 倍。第一封信不要急著賣東西，這件事在 BD 漏斗的前期是真的成立。

**Anthropic 好為人師的兩面**

> 公關危機時那種「我來教育用戶」的嘴臉很難領教；但同一個性格也讓他們的技術與科普文章特別用心。Unknown Unknowns 和 effort 教學就是兩篇佳作。

**兩家 computer control 的差距已經很誇張**

> 用過 GPT 跟 Claude 兩者的 computer control MCP 之後，任何人都會驚訝他們差異已經如此巨大。一家操作非常絲滑流暢且檢查細心，另外一家會亂搶你的滑鼠跟輕易放棄操作。

## 生活・雜感

**返台才發現台灣富起來了**

> 這次返台真的感覺台灣富起來了——醫院、餐廳、捷運上常聽到的路人話題都是買股票、投資，電梯裡的上班族在聊去日本去歐洲。習慣吃的餐廳兩年內套餐從 160 漲到 220，以前 160-200 的 Uber 現在要 250-300。住泰國的我好跟不上。

**邊界感**

> 順便學一個詞：邊界感。雖然很多人說是支語，但我覺得無可取代。過年好久不見的親戚一直刺探隱私——薪水多少、結婚沒——這就是沒有邊界感。

**武俠版熱水機**

> 嚴冬大雪紛飛，大俠方至客棧，意欲飲水解渴。店主：請用溫開水。「有滾水乎？」店主：先按解除鎖定，再按熱水。

**越南咖啡店網路品質**

> 到越南後一開始看到路邊那種門戶敞開、擺矮桌加露營椅的咖啡店，都會想避開，覺得網路不穩。後來才發現這種地方網路品質最好——因為一堆越南少年點一杯咖啡就在那邊玩手遊，萬一延遲高誰要來消費。

**第一性原理：記仇就刪掉**

> 第一性原理吧——記仇會讓事情變得更好嗎？不會，那就刪掉。

**AI 辨識路倒的烏托邦還很遠**

> 有人希望 AI 能偵測河濱公園的路倒並自動報警。問題是覆蓋整個河濱的偵測等於天網，隱私輿論會爆炸，也不符經濟效率；連特斯拉 FSD 全世界法規放行的地方都寥寥無幾。最務實的現行做法是把偵測點戴在自己手上（Apple Watch 跌倒偵測自動報警）。這不是全台沒有，是全世界都還沒有。
