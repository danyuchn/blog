## 開發・資安踩坑

**Vercel 臨時公開頁的兩個坑**

> 新 project 部署出來的 URL 預設開著 Deployment Protection（Vercel Authentication），外部訪客拿到 401。另一坑：`<proj>.vercel.app` 裸別名可能是別人佔走的空殼，自家自動更新的 prod 別名是 `<proj>-<team>.vercel.app`。發連結前先 curl 驗內容。

**iQOS 藍牙逆向工程**

> 我真的是服了 Claude Code。前幾天在 Reddit 看到有人分享 Claude Code 是如何幫他解掉惡意勒索軟體、救回資料。今天我突發奇想，把 iQOS 接進電腦，問他能不能讀到資料。結果他真的自動幫我上網找資訊，找到有人逆向工程開發的開源專案，閱讀裡面的邏輯，然後自己寫一個腳本，硬是透過藍牙把 iQOS 的資料讀出來了。

**只靠光線傳檔案**

> 讓兩台手機無 wifi、無藍牙、無任何通訊協定，只透過光線傳檔案：把檔案拆成一堆 chunk 轉碼成 QR code，發送端在螢幕上一秒 40 幀快速顯示，接收端再快速解碼拼回。已實證達到每秒 128KB。

**本地模型抓機敏資料的召回率**

> 去機敏我有實測。`qwen2.5:1.5b` 3/16，快但漏太多；`qwen3-vl:8b` 14/16，很快但答案欄位異常且漏人；`qwen3-coder:30b` 15/16，單測尚可但完整流程超過 110 秒且中途失敗；`qwen3.6:35b-a3b` 16/16，最完整也最穩定。不要直接讓本地模型去處理，先用 regex 腳本掃一次，本地模型只是用來涵蓋邊界狀況。

**ENV_SCRUB 打開，AUTOMODE 就回不去**

> 冷知識：如果 `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1`（變數剝離這個設定打開），AUTOMODE 就無法變成 default，default 會是 manual。

**別讓 agent 自己去申請 API key**

> 你真的敢讓他自己申請，然後讓 API key 明文留在 session log 裡面嗎？

**每天掃一次自家官網的前端**

> 接下來要每天掃一下公司官網的頁面，看看主管有沒有把 API key 寫在前端。
## 工作流・方法論

**廣泛焦慮症怎麼看風險報告**

> 教大家有廣泛焦慮症的我會怎麼看一份風險報告：一、8.6% 的風險太高了，不可以接受。二、萬一發生，70% 的狀況跟我想像的一樣、甚至更糟？不可接受。三、我們從不會只擔心 30 天後的事情，30 年還差不多。

**禮貌不等於替對方找理由**

> 「I know things have probably been busy on your end」看似體貼，其實是在替對方的沉默編一個他沒說過的理由。AI 寫客戶信常有這種隱性的居高臨下，套過 polite skill 還是要自己看。

**AI 影片的甜蜜點**

> 我覺得還是自己錄旁白出鏡，但是畫面動畫用 AI 輔助，會是甜蜜點。

**免費諮詢只給 15 分鐘**

> 直接約 BD call 15 分鐘免費，想約第二次請付費諮詢，這個付費諮詢未來如果有成案是可以抵費用的。比照律所、會所行之有年的成熟做法，可以確保篩選掉不想付費的客戶。我教齡 15 年，從一開始免費問到飽，到現在只敢免費 15 分——免費的絕對會被不少人當狗屎，放鳥的、出言不遜的、白嫖的，什麼我都有看過。因為我們都不是菩薩。

**不用選邊站**

> 為什麼要選邊站？Claude 產文案，GPT 的瀏覽器控制負責在 meta 後台找路，不是最完美的嗎。

**語意不模糊就夠了**

> 他才是真正知道怎麼用的。LLM 只要你今天語義不模糊，拼字錯誤、語音辨識錯誤都沒有關係。重點是他的下指令方向非常清楚，邏輯思路也清楚，可以驗證 AI 的回答，所以才能夠這樣協作。

**黎曼猜想那次，提示詞只是加油打氣**

> 傳統數學家持續 30 年只能推進 0.8%，這一次推進了 25.6%。最有趣的是文裡面寫，提示詞根本沒有下什麼專業內容，就只是一直鼓勵 AI 幫 AI 加油。Claude 花了一天半協調大約 60 個子代理，執行了 2,400 個 shell 指令並互相審查，而人類的輸入大多限於「繼續堅持」或「相信自己」。
**兩種模型混搭法**

> 換模型有 cache miss 問題，最常用的是 subagent。路徑還不明確時，主 agent 用聰明的、雜活丟給低階的臨時 subagent；路徑已經明確、只剩少部分困難點時反過來，主 agent 用低階的，臨時叫聰明的 subagent 來當一次性顧問或驗收。

**copyparty 配 tailscale**

> 在手機上看家裡電腦的任何檔案：Markdown 直接內建渲染預覽、HTML 直接網頁版檢視、300 多頁的電子書 PDF 秒速開啟、1GB 多的影片也沒有延遲。拿它來搭配 remote control 的 Claude Code 或 Codex，簡直是一絕。

**Connector 終於能寄信了**

> 之前好幾位客戶就是卡在想設置雲端排程寄每日市場週報、或寫入 Google Sheet 表單——雲端 server 只吃官方 connector，以前最多只能寫草稿或在 Drive 創立全新檔案。現在官方 MCP 開放了寄送信件跟更新現有檔案。

**影片後製的神**

> Davinci Resolve Studio 配 MCP 給 Luna Max 操控，就是新世界影片後製的神。Luna Max 做這種雜活真的是世界第一名。

**先用開箱即用的 harness**

> 建議直接 codex。除非你非常瞭解 hermes 的原理跟架構，不然 codex 或 claude code 的 harness 目前來說是開箱即用最穩定的。

**Anthropic 在中國**

> 在小紅書上搜 Claude/Anthropic，會發現這是少數曾經明確「辱華」但最後安然無事的。現在看到的都是一片「太好用/怎麼翻牆用」。所以實力還是硬道理。

**Claude 撼動華爾街**

> Claude 是那個唯一可以撼動華爾街各大軟體股股價的 AI。你說呢。

**Karpathy 三姓家臣**

> Andrej Karpathy 宣布加入 Anthropic。OpenAI → Tesla → OpenAI（回鍋）→ 離開 → Anthropic。這應該是 AI 圈最強的三姓家臣了。不過換個角度看，頂尖人才往他認為最有潛力的地方跑，本身就是一種市場訊號。

**只講方便不講風險的講師**

> 凡是講方便，不講風險、資安、權限、審核的講師，基本都可以當詐騙看待。
**知識的詛咒**

> 你以為 google 就能得到的資訊，在很多人眼裡是非常感謝有人替他們收集的。人家賣得出去是他有本事，只要不傷天害理沒什麼好批判的。脆果然是最厲害的 vibe coding 對抗式審查工具。

**先當社群分享者，再談變現**

> 最好的點子很多時候不是你自己想出來的，而是你深度參與社群、解決社群痛點來的。先不要想著什麼 idea 都要變現賺錢，先當個無私、熱情的社群分享者，等你在社群紮下了根，那些人就會成為你的第一批客戶。

## 生活・雜感

**返台才發現台灣富起來了**

> 這次返台真的感覺台灣富起來了——醫院、餐廳、捷運上常聽到的路人話題都是買股票、投資，電梯裡的上班族在聊去日本去歐洲。習慣吃的餐廳兩年內套餐從 160 漲到 220，以前 160-200 的 Uber 現在要 250-300。住泰國的我好跟不上。

**邊界感**

> 順便學一個詞：邊界感。雖然很多人說是支語，但我覺得無可取代。過年好久不見的親戚一直刺探隱私——薪水多少、結婚沒——這就是沒有邊界感。

**武俠版熱水機**

> 嚴冬大雪紛飛，大俠方至客棧，意欲飲水解渴。店主：請用溫開水。「有滾水乎？」店主：先按解除鎖定，再按熱水。

**越南咖啡店網路品質**

> 到越南後一開始看到路邊那種門戶敞開、擺矮桌加露營椅的咖啡店，都會想避開，覺得網路不穩。後來才發現這種地方網路品質最好——因為一堆越南少年點一杯咖啡就在那邊玩手遊，萬一延遲高誰要來消費。

**第一性原理：記仇就刪掉**

> 第一性原理吧——記仇會讓事情變得更好嗎？不會，那就刪掉。

**AI 辨識路倒的烏托邦還很遠**

> 有人希望 AI 能偵測河濱公園的路倒並自動報警。問題是覆蓋整個河濱的偵測等於天網，隱私輿論會爆炸，也不符經濟效率；連特斯拉 FSD 全世界法規放行的地方都寥寥無幾。最務實的現行做法是把偵測點戴在自己手上（Apple Watch 跌倒偵測自動報警）。這不是全台沒有，是全世界都還沒有。

**我只是不喜歡人**

> 從小我一直以為自己天生不擅長也不喜歡領導人，不能當主管帶團隊；AI Agent 出現之後我才發現，我只是不喜歡人。
