最近幫自己做了一個 SKILL，可以叫用幾個現成的開源套件，用很省 token 的方式，在電腦裡一大堆 Claude Code / Codex 對話紀錄裡找到我要的那一場。而且不只是關鍵字比對，還支援語意模糊搜尋。

會動手做這個，有三個起因。第一個是備課的時候，常常需要把之前某個 session 裡做過的示範拿出來現場重播，但我只記得大概是幾天前做的、做過什麼，具體關鍵字早就忘了。第二個是有時候忘記把進度寫進知識庫的工作日誌，需要回頭翻對話紀錄才能拼出專案的動態跟進度。第三個是想看看上禮拜到底做了什麼，用更強的 SOTA 模型（比如 Fable 5.1）重新審查一次上週的成果。

有沒有人對這個 SKILL 有興趣？如果有，讓我知道，我想評估要不要花額度把它整理上 Git。
