剛剛嘗試用降價後的 GPT-5.6 Luna MAX 幹雜活，真的他馬太好用了。

此次分派的任務是兩個：一是用瀏覽器去各家銀行跟收款平台（我幫忙登入後）把缺漏的報表弄下來，故意不走 API／MCP／CLI；二是去幫我把 Claude Code 那邊的 harness 同步到 Codex 這邊來（已有 SKILL）。兩個都下 `/goal`，前者 22 分鐘圓滿完成，另一個跑了一個小時現在還在有序進行中。目前看周額度才耗 1%，用 token 換算 API 價格大概 3.14 USD。

![終端機顯示 agent 完成後回報四份財務報表已下載並核對格式與日期，底部標示 Worked for 21m 49s](/blog/assets/posts/gpt-5-6-luna-max-grunt-work/1-luna-max-goal.jpg)

這麼高的性價比，已經不是跟 A＼比的問題了。我覺得 DeepSeek 的用戶可能都會拉走，畢竟論 token efficiency、論 agent 能力、論 computer／browser use，DeepSeek 應該也很難跟 GPT-5.6 打。我願稱 GPT-5.6 Luna 是新一代的雜活之王。

他最好用的是做土法煉鋼的瀏覽器爬蟲，對付那種沒有 API、又愛擋爬的網站。以前要馬就是讓 AI 下載各種套件或腳本仙拼仙，要馬就是去第三方 API 花錢買。但有時候我就只是一次性想要爬，不想硬幹冒被封鎖的風險，也不想為此花錢跟第三方買資料。這時 Luna Max + goal 開下去跑整夜，醒來才掉 5% 血量，任務順利完成。

這種東西直接操縱你的真實瀏覽器來爬，token、指紋、速度、頻率全部都跟人類相仿。我目前天天爬也沒有被 403，放著跑一個晚上就好了。GPT 5.6 不管哪一個等級的模型，瀏覽器操控跟電腦控制的能力都遠勝 Claude；Claude 在瀏覽器操控的準度跟效率上，真的遠遠輸給 GPT。

LUNA 是幹雜活專用。對於那種傳統很耗費 token 的任務，比如無 API 又會擋爬蟲的網站，只好靠瀏覽器 MCP 爬取；或者是人在外面遠端用 computer use 操控電腦做事情，Luna 是不二選擇。

我最常用 LUNA 的場景有幾個。一是爬社群網站的文章做輿論觀測，理由是不想冒風險對幹反爬、偶爾查頻率不高，不想特意買第三方 API 的資料。二是幫我去航空公司的網站找里程票機位，機械性的點來點去幾十個天數組合，看一眼有沒有位置，抄寫空位資料跟航班資訊給我來做最終決定，但是又沒有 API 能做這件事。三是幫我去各家住宿平台比價，甚至申請最低價格保障退款，理由同上，且他的智力已經足夠理解最低價格保障的規則跟條款。四是人在外面，用手機遙控告訴 LUNA：幫我去打開 LINE／Messenger，把對方要的文件下載下來，叫 Sol／Terra 處理後，你去 LINE 發還給他——目前已經用這個方式遠端完成不少。同理 104 篩選職缺、一大堆平台查飯店比價，都是 Luna Max 我最愛用的場景。感覺是不是應該拍一部影片示範？（補記：後來真的拍了，EP.34 <https://youtu.be/8Sxw1Mdcl8Q>）

![終端機正在逐點測試 BKK-KIX 各日期，右側 Chrome 開著 ANA 日文特典預約頁面的日曆選單，上方顯示 ChatGPT started debugging this browser 提示條](/blog/assets/posts/gpt-5-6-luna-max-grunt-work/2-ana-award-seats.jpg)

謝謝 GPT 5.6 Luna Max，前天才幫我刷到曼谷東京商務艙兩位。用過 ANA 的人才知道他們的里程票系統之爛、規則之複雜。

會在那裡「全方位」嫌棄某某模型的人，其實就是你的想像力太過狹隘，想要用拉踩某些模型顯現自己很懂。每個模型都有他適用的 use case，端看你有沒有想像力。在我眼裡，就連 Gemini 都有他的一席之地。

我都跟別人說，GPT 5.6 Sol 是瘋狗。當你給他 /狗死 下去（我還會順便放音樂，LISA 的「狗死～狗死～」），他就會死死咬著目標把它做完，不做完不罷休。

最近除了 5.6 Sol，最愛用的就是 5.6 Terra high。這根本就是雜活第一優選，操縱瀏覽器跟電腦仍然非常準，連複雜的里程查票任務他都能幫我搞定。重點是額度省之又省，可以把 Sol 用在更重要的事情之上。用過 GPT 跟 Claude 兩者的 computer control MCP 之後，任何人都會驚訝他們差異已經如此巨大：一家操作非常絲滑流暢且檢查細心，另外一家會亂搶你的滑鼠跟輕易放棄操作。

X／Threads 這類社群網站，Claude、Codex 的直接 WebFetch 常被擋，要繞瀏覽器；Gemini 卻能直接讀。Reddit 對 Claude 特別不友善，Codex、Gemini 反而順。模型不是只比聰不聰明，還要看資料入口。
