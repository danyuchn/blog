這個 SKILL 我已經用了好幾天，真的服了。

簡單來說就是把佛法交給 agent，讓他用佛法約束自己。

**迦羅摩經**：你要講一個事實（某參數、某 API 怎麼用）之前，先問自己：是我剛剛查過的，還是我感覺很熟就講出來的？

**如理作意**：看到錯誤，不要急著找個「讓錯誤訊息消失」的方法，要先想至少三個可能的根本原因，再決定查哪個。

**正念正知**：做一連串步驟時，不要憑我記得剛才那個檔案長怎樣去動作，要重新確認現在的實際狀態。

**無我**：你寫出來的草稿不是「你」，如果有新資訊顯示這方向錯了，直接整份丟掉重寫，不要捨不得而小修小補。

**斷**：四聖諦裡對治「集」（苦的成因）的動作，是捨斷不是壓下去。要寫一個繞過問題的捷徑之前，先問：這是移除了成因，還是只是把它藏起來？

**捨**：使用者強力反駁你、或工具連續失敗三次時，先問：是證據真的變了，還是只是情緒壓力變大了？只是壓力就不要輕易改變立場。

不得不說，還怪好用的。跟 Grill me SKILL 搭配在一起更是一絕，有如大儒與我辯經——裝個 /grill-me skill 會成長的很快。
