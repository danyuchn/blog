在實際教學的過程中，最常看到一個耐人尋味的矛盾：對於硬體資源極度吃緊的電腦來說，CLI（命令列介面）絕對是最好的解法，因為它佔用的系統資源不過是 GUI 的零頭。然而現實往往是，電腦資源最不夠用的族群，也剛好最不可能學會 CLI。

這完全不是貶義，只是教學現場看過太多讓人捏把冷汗的景象：垃圾桶從來沒清過、桌面鋪滿密密麻麻的截圖、兩年前下載的安裝檔還靜靜躺在下載資料夾裡，整台電腦的硬碟容量只剩下 1.8G，記憶體狂吃 SWAP，整台機器卡到寸步難行。

而每當電腦資源被擠壓到極限、系統狂吃 SWAP 喘不過氣時，大家轉頭最常丟出來的問題往往出奇一致：如果想在自己的電腦上跑本機模型，硬體到底要多好？

## 跑本機模型的硬體迷思與極端想像

問起跑本機模型需要什麼硬體，答案其實取決於你手邊的設備條件，要求往往沒有大家想像得那麼高。但在社群討論裡，大家對硬體門檻的想像卻經常走向兩個極端。

第一個極端是把「能跑通」當成「速度不錯」。在 reddit 上就有人分享用 16GB RAM 跑通 deepseek V4 flash，速度還不錯喔！33 sec / tok（注意單位）。

另一個更極端的例子，是前陣子的笑料承包：Google 工程師要跟高職學學 AI 正確姿勢，5000 跑本地大模型。如果這是真的話，那下禮拜台股、SK 海力士、三星還不繼續跌爛。

## 主流模型的真實門檻

開完玩笑，認真討論主流模型的運作，真實門檻其實既沒有天方夜譚的神話，也不需要高不可攀的機房設備。

目前 3.6 版的 27B 以及 35B A3B，已經被公認是性價比最高的本地小模型之一。以 3.6 27B Q4 量化版為例，其實只要一臺配備 48GB RAM 的 M4 Pro 就能順暢跑起來，速度大概 20-30 tok/s。

而且開源生態的進展非常快。前幾天 Qwen 官方在社群上宣布了下一批開放權重，如同官方貼文截圖所示：

![Qwen 官方帳號在 X 上宣布 Qwen3.8-Max 的貼文，文中「下週將釋出 Qwen3.8-Max 的開放權重，Qwen3.8-27B 也將開放權重與大家見面」一句被反白標示，下方列出 autonomous coding、long-horizon mastery、native multimodal 等賣點與每百萬 token 輸入 $2.0、輸出 $6.0 的定價。](/blog/assets/posts/cli-resource-paradox-local-models/1-27b-open-weights.jpg)

截圖中特別預告了 27B 的開放權重，非常令人期待。希望 27B 開放權重後可以有人出量化版，也希望之後能夠有 MOE 版本的小模型。

## 電腦是生產力工具，該升級就給它買吧

聊到這裡，大家終究要面對最核心的現實抉擇：到底要不要為了跑本機模型特別去買電腦？

至於要不要為了這些買電腦——電腦絕對更貴。Mac mini M4 Pro 48GB RAM 五月買五萬多，現在去看九萬了。所以用了幾年還能保值這句話不是騙人的。

但更根本的評估原則在於工具定位。電腦終究是拿來產出價值的生產力工具。如果家裡擺著的那台機器本來就是連垃圾桶都塞爆、容量只剩 1.8G 的老破小，它在日常工作裡本來就給不了你什麼生產力，更遑論拿來跑本地模型。想要穩定流暢的工作體驗與實用的本機算力，該投資的時候就給它買下去吧。

  - M4 Pro 48GB RAM 運行 Qwen 3.6 27B Q4 量化版：速度約 20-30 tok/s（每秒產出 20-30 個 token，具備日常工作流實用性）。
- 主流模型與開放權重資訊：
  - Qwen 3.6 27B 與 35B A3B：公認高性價比的本地小模型配置。
