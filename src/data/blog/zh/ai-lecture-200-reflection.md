週日早上辦了一場免費的 AI 線上講座。

報名人數超過 450 人，實際出席約 200 人（出席率大概 45%）。雖然時間剛好撞到母親節聚餐的中午，但 Zoom 後台數據拉下來，留座時間平均超過 75%，後續的問答環節甚至熱絡到延長了半個小時。

這讓我想起十年前在大安站的實體教室。那時一間教室擠滿 100 個人，我在講台上連講四個多小時 GMAT，學員從早上十點坐到下午兩點半，中間只休息一次，喝口水就接著講。

如今那種高度專注的時光在線上又重現了。只是這一次的主題不再是商學院考試，而是怎麼用 AI 真正改變一個沒有程式背景的知識工作者的工作方式。

## 現場提問揭露的真正焦慮

平常做完展示、講完案例，問答環節通常是一片安靜，大家點個讚就各自離線。但這場講座長達 30 分鐘的問答裡，各行各業的人一個接一個提出具體問題。

與會名單裡有業務、專案經理（PM）、行銷、研究與數據分析人員、設計師、會計師、軟體工程師，也有補習班負責人。

提問的場景各不相同：
業務問「客戶會不會繞過我直接用 AI 估價？」
PM 問「我寫的 PRD 會不會被取代？」
會計問「事務所是不是要關門？」
設計問「我的 portfolio 還值錢嗎？」

每個人的切身問題不同，但底層指向同一個焦慮：AI 已經改變職場了嗎？我準備好了嗎？

這種焦慮並不是因為大家沒碰過 AI。從當天報名數據來看，超過半數報名者自評對 AI 的熟悉度已經達到 4 到 5 級，而且非工程師族群佔了絕大多數。大家焦慮的不是「如何跟機器聊天」，而是「當機器開始自主做事時，我的位置在哪裡」。

## 從「對話生成」跨入「自主執行」

這場講座的核心主軸，正是這個本質質變：AI 的重心已經從單純的「對話生成」，演進為「自主執行的 Agent AI」。

過去一年，大部分資源投在 Agent AI，而不是對話生成。這也反映在我自己的工作形態上——從「AI 輔助工具」轉變為「高度協作夥伴」。

在美國職場，這件事已經是現在進行式。各大公司如何「強制」員工使用 AI，包含培訓、工作坊與生產力 KPI。公司在量化 AI 成效時，看的是 token 用量、工時節省統計，以及人力替代的案例。Anthropic 工具已可取代律師事務所初級律師、部分專業軟體，華爾街軟體股也隨之產生波動。

更關鍵的轉變在於非工程師的普及。AI 已經不再是工程團隊的專屬工具，而是各領域工作者重塑工作流的槓桿。

## 一個指令完成的三步自動化鏈

為了讓大家理解「自主執行」與「單純對話」的具體差距，我在講座中展示了一條全自動工作流鏈。

這是一段 60–90 秒的全程預錄展示（預設好的對話，現場不跑），直接拿當天講座累積的 294 筆真實報名表數據作為原料。

在整個過程中，我只給了終端工具 Claude Code 一個指令：「去看看今天來的人是誰，給每種人創一個真實背景，幫他們針對最可能去的公司客製履歷。」中間沒有手動干預任何一個步驟，系統自主完成了三步自動化鏈：

第一步：讀取試算表中的報名數據，自動統計與會者的專業背景分佈。
第二步：依據統計結果，自動生成三個具代表性的虛擬背景角色（業務、數據分析師、行政專案人員）。
第三步：針對這三個角色啟動履歷客製流程，比對目標職缺要求，產出三份排版完整的客製化 PDF 履歷——業務對應 Salesforce、數據分析對應 McKinsey、行政對應 Google。

這正是 ChatGPT 物理上做不到的事：跨工具讀資料、多步驟判斷、產出檔案、全程無人工。

## 工具會變，指揮的決策思維不變

過去半年我拍了三十幾部 Claude Code 教學影片，慢慢開始有新的感觸：工具會變，思維不變。

出一張嘴也是有學問的。真正想分享的不是「按哪個鍵」「下哪個指令」，而是指揮的邏輯思維——拆分任務、規劃驗證、分配職責、風險管理。

這些思考框架，跟我十年前在大安站實體教室教 GMAT 本質上一模一樣。GMAT 教的是在限定時間與有限資源下如何做出最佳決策；指揮 Claude Code 也是同樣的道理。只是工具從當年的鉛筆，換成了現在的 Sonnet 4.6。

## 落地應用時的邊界與建議

以我自己在講座後處理分眾名單的經驗為例，面對完全新接觸的名單，他們是冷的，先走信任建立（例如社群互動或提供講座錄影），不直接做商務開發。

## 附錄：講座技術細節與運作機制

- Claude Code：具備本機環境讀寫、命令列指令執行與工具調用能力的命令列 AI 工具，能自主執行多步驟任務並輸出最終交付檔案。
- Agentic 架構：從傳統對話工具演進為可自主執行任務的 Agent，能跨工具讀資料、進行多步驟判斷並產出檔案。
- 三步自動化技術流程：讀取 Google Sheets 試算表（294 筆報名資料）分析與會者背景分布，自動生成 3 個代表性假角色，再針對每個角色跑 job-tailor 產出 3 份客製 PDF 履歷。
- Sonnet 4.6：文中用來與十年前鉛筆對照的大語言模型。

回望十年前擠滿學員的大安站教室，媒介雖然從黑板換成了終端螢幕，但教學的本質始終如一。當外部工具快速翻新時，最能讓人站穩腳步的，從來不是盲目追逐新功能，而是建立拆解問題、定義邊界與做出決策的能力。只要指揮的架構清晰，工具再怎麼迭代，節奏依然在自己手裡。
