我在此宣布：最適合教育界的老師們學習 Claude Code／Codex 的免費工具就在這裡。

作為有 15 年教齡的留學考試老師，完全沒有寫程式的技術基礎的我，去年在自學摸索 Claude Code 時，遇到很多困難。但是克服這些困難後，得到的回報也是巨大的：在兩個月內，我每天原有的例行教學工作效率提升 4 倍，同時教學品質跟滿意度都雙雙提升。

於是我回來思考，到底怎樣讓跟我一樣的非編程背景的老師們，也能夠少走彎路快速上手 Claude Code／Codex 呢？

直到我看到了 Carl Vellotti 的 claude-code-pm-course。他的這個專案是直接把整套 PM 的情境帶進 Claude Code／Codex，不是另外錄一套課程，而是讓 Agent 在設計好的情境裡一堂一堂課帶你走過每個功能。也就是讓 Agent 直接教你怎麼用 Agent。

於是我鼓起勇氣寫信給 Carl，詢問我能不能借鑒他的骨架，動手做一個給老師用的版本。他很大方地同意了。

因此，今日隆重推出 Claude Code for Tutors。

<https://github.com/danyuchn/claude-code-for-tutors>

各位老師們，你只需要下載、解壓在一個資料夾裡，打開 Claude／ChatGPT 桌面版登入付費帳號，切到 Code／Codex 模式選擇該解壓的資料夾。直接講「開始」，你就能夠一課、一課完整走過所有的老師會遇到的情境，由 Claude 親自當你的老師，在你熟悉的情境中教你如何活用 Claude Code／Codex。

跟原版不一樣的是，我也加入了許多我自己使用 AI 的心法，比如如何驗證、如何抓介入的時機、如何規劃……。因為我相信，未來工具會換，但是這一套與模型互動的心法，是絕對可以陪你走得很長很長。

想要免費自學更多，也請來：<https://www.youtube.com/@AgentcrewAcademy>
