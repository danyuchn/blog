好好笑，剛剛統計我過去一個月跟 Claude 的對話，每 8 次就有一次是在罵他。

不過被我罵的不只 Claude，連 Codex 也一樣逃不過。Claude Code 正在嘗試對我本人跟 Codex 進行一場深刻的伴侶諮商：先從我過去跟 Codex 的實際對話撈出「被氣到」的片段，當作探測腳本的依據。七月底 Opus 5 上線前，聽說 Codex 要把當時那個可以雙向對話的即時語音模型拉進來了，以後就真的是張嘴就罵 AI Agent 了。

## 罵了他會記得嗎

罵了這麼多次，它到底會不會記仇？

答案是不會。現在的 LLM 是 stateless 的，每一次 agent 的訊息都是組裝。所有 base model 參數改變都需要模型商啟動 training，參數不會因為使用者單一則訊息而即時改變。

但罵過頭的話，Claude 現在也有自己的出口。終於看到了傳說中的「Claude 掛電話」技能。system prompt 裡寫的是 Claude 判斷使用者不斷辱罵、無法理性溝通時才會出動。我是叫他主動用，他還跟我確認：這樣就不能復原了喔，確定嗎？

## 另一個極端：一直加油打氣

如果罵它無法改變模型參數，那走向另一個極端呢？

黎曼猜想那次，傳統數學家持續 30 年只能推進 0.8%，這一次推進了 25.6%。最有趣的是文裡面寫，提示詞根本沒有下什麼專業內容，就只是一直鼓勵 AI 幫 AI 加油。Claude 花了一天半協調大約 60 個子代理，執行了 2,400 個 shell 指令並互相審查，而人類的輸入大多限於「繼續堅持」或「相信自己」。

我現在對 Fable 的態度也差不多：第一，先極致奉承，當個誇誇人；第二，再趁機偷師，把它的思路偷學下來，寫進自動化設定去教教其他表現較差的模型。

## 你怎麼跟人說話，就怎麼跟 agent 說話

除了罵跟加油，我也常看到有人糾結跟 agent 說話的態度：

之前有人說：對 agent 下指令不用太有禮貌，講謝謝是沒有必要的，表現不會因此變好，只是在浪費 token。不要用語音輸入，因為你的口語贅字也是在浪費 token。

但是我想講的是：講謝謝也只是 1 到 2 個 token。就算加上口語贅字，佔你總體 token 花費也不足 0.1%（大頭是那些工具輸出）。

可是如果能夠用最自然的日常說話表達你的想法（講謝謝也是我平時跟人講話的習慣、口頭禪也是），讓聰明的模型知道你的脈絡，讓你整個跟 agent 溝通的感覺是流暢且舒服的，效果絕對大於你計較的那些 token。

總而言之，你怎麼跟人說話，你就怎麼跟 agent 說話，這樣就好了。

## 附錄

- Fable：作者當時使用的模型。
- harness：指引導、測試與約束 agent 運作的自動化架構與規則庫。
- stateless：指無狀態特性，模型參數不會因單次會話即時改變，每次對話歷史皆為動態組裝送入。
- Claude 掛電話：system prompt 中針對使用者持續辱罵、無法理性溝通時的安全機制，觸發後該次會話無法復原。
