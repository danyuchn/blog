## 接到別家介面，能力瞬間解放

最近看了 X 上的不少分析跟小道消息，我有一個預感：最快一個月，最遲年底，Gemini 會重回 agent 排名第二的位置。

我自己就很愛用 Gemini 3.8 Flash，因為：

1. 原生多模態第一名
2. 我心中的寫作第一名，潤稿超自然
3. 速度快
4. 單 call API 定價實惠
5. 訂閱制量大管飽
6. 偶爾拿來當主對話（當 Claude 額度快滿時），也能感覺到比 Codex 容易合作

更不用說，99% 的人在酸 Gemini 的時候都沒有發現的事實：他們家的原生 Harness（網頁版、AGY）是垃圾。一旦你用 API 接到別家的 Harness，能力瞬間解放。

雜活之王就他跟 Luna，但是 Luna 沒多模態又被降智 哭。Gemini 跟接 API 比起來，幻覺率略高，但是作為 agent 的能力已經是堪用了。幻覺率還是略高，而且有提權越權現象，所以我都會掛更嚴格的 hook + 讓 Claude Code 掛 monitor 即時監控。

## 專心做大文豪就好

阿公寫作也非常強（「阿公」或「雙子星阿公」是我對 Gemini 的暱稱）。不得不說，在各家都在卷 coding 的情況下，有寫作強的模型，我很感激 Google。

自動發文如果用 Gemini 來潤稿，會自然得多、不惹人厭得多，去換換模型吧。然後讓 Claude Code 叫 AGY，寫給人看的文件、信件更爽，簡直是大文豪。

有次朋友傳東西給我看，我第一直覺就是想到玫瑰瞳鈴眼，然後我就派出大文豪雙子星阿公（Gemini 4 Argon）編劇本。結果……太強了（認真）。我完全覺得 Gemini 他們家可以不用卷 coding，專心做大文豪就好。文筆好到狠甩其他模型幾十條街。別的模型是起承轉蛤，他這個真的是起承轉合。

阿公額度燒的幅度還是有些驚人……但聽說 Gemini 4 Carbon 會非常強，值得期待。

## 每月 140 美元的御三家配置

GPT 的 20 刀這個檔位是甜蜜點了，因為：

1. 現在的 Codex 根本不值得花上 100 刀，100 刀以上都建議用 Claude
2. 20 刀主要是買他們家的生圖功能（生圖這塊確實還是斷崖領先），還有電腦跟瀏覽器操縱，當然全部都是讓 Claude 去派工
3. 只用 Luna/Terra 分擔粗工跟審查。20 刀要用 Sol/Astra 還不如用 Opus 5.5...

我的御三家黃金搭配建議：

- 100 刀 Claude：會送 100 刀 API，直接拿來跑自動化排程，只用 Haiku 跟 Sonnet，平常要人協作的任務基本用 Opus 5.5 med
- 20 刀 GPT：用法如上
- 20 刀 Gemini：貪他們家的 5TB 雲端硬碟、每月 200CU Colab 跑開源模型 qwen 3.8 27b、還有 flash 3.8 量大管飽做所有多模態相關任務、Argon 大文豪管寫作

這樣 140 刀每個月，美滋滋。

## 附錄：名詞與設定說明

- **Harness**：指包裹模型的操作外殼與執行環境（如網頁版或命令列工具）。
- **AGY**：Google 的終端命令列工具。
- **Hook 與 Monitor**：Hook 是在 agent 執行操作前後自動攔截檢查的規則；Monitor 是即時監控程序。
