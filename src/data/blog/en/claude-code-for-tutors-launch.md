Here's my announcement: the free tool best suited for teachers learning Claude Code and Codex is right here.

I've taught test prep for 15 years and I have no programming background at all. When I started teaching myself Claude Code last year, I ran into a lot of trouble. But once I got past it, the payoff was huge: within two months, my daily routine teaching work got 4x more efficient, and both teaching quality and student satisfaction went up.

So I came back to the question: how do teachers like me, with no coding background, get up to speed on Claude Code and Codex without all the detours?

Then I came across Carl Vellotti's claude-code-pm-course. His project brings the whole set of PM scenarios straight into Claude Code and Codex. It isn't a separate recorded course. It lets the Agent walk you through every feature, one lesson at a time, inside scenarios built for exactly that. In other words, the Agent teaches you how to use Agents.

So I worked up the nerve to email Carl and ask whether I could borrow his skeleton and build a version for teachers. He generously agreed.

And today, I'm launching Claude Code for Tutors.

<https://github.com/danyuchn/claude-code-for-tutors>

Teachers, all you need to do is download it, unzip it into a folder, open the Claude or ChatGPT desktop app and sign in to a paid account, then switch to Code or Codex mode and pick that folder. Just say "start," and you'll go lesson by lesson through the situations teachers actually run into, with Claude itself as your teacher, showing you how to put Claude Code and Codex to work in settings you already know.

What's different from the original is that I also put in a lot of my own principles for working with AI, like how to verify, how to catch the moment to step in, how to plan. Because I believe the tools will change, but this set of principles for working with models will stay with you for a long, long time.

If you want more free self-study material, come here too: <https://www.youtube.com/@AgentcrewAcademy>
