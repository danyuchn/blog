# agy 提示詞模板（抄自 2026-10-25 實際使用，括號為佔位）

用法：`agy -p "<提示詞>" --effort high --add-dir <暫存夾> --dangerously-skip-permissions > <log> 2>&1 &`（或經 `~/.claude/scripts/ext-run agy -p …`）。agy 只寫指定的輸出檔，原稿不改。暫存夾用 scratchpad 或 mktemp，不放 repo。

## 1. 中文潤稿

```
你是中文編輯，要把這份部落格草稿改得更自然、更像作者本人在說話。先讀 {暫存夾}/brand_voice.md（作者的寫作風格）與 {暫存夾}/B9-提示詞怎麼寫.md（作者給 AI 的提示詞寫法）。草稿：{暫存夾}/draft-zh.md ，把改好的完整全文寫到 {暫存夾}/draft-zh-agy.md（只寫這一個檔，不要改原檔）。讀者是第一次看到這個部落格、不會寫程式的人，不要加入只有作者懂的內部名稱。起手提示詞範本的 text 區塊照 B9 改成口語、一段話講完。

規則（全部必守）：
1. 正式但口語的第一人稱，句子短，段落 2–5 句；轉折用「但／不過／其實」，不用「然而／此外」。
2. 少術語：術語過多或讀者可能看不懂的地方改成白話（例如 {術語 1}、{術語 2}），但指令名稱（{指令與產品名清單}）保留原樣。
3. 絕對不准改：任何數字、百分比、日期、金額；所有 > 引用區塊裡的原話一字不改；程式碼區塊不改；圖片與 video 那幾行原樣保留。
4. 不准新增觀點、比喻、總結句、金句、排比、「不是A而是B」句型、emoji；不准加「總結來說」「讓我們」這類話；結尾的收束句保留。
5. 可以重組句子、合併或拆段，但 ## 標題文字與順序不變。
6. 台灣繁體中文用語。
寫完檔後回覆一行 DONE。
```

附錄潤稿時，規則 2 改為「不改技術名詞、程式碼、欄位名」，規則 5 保留。

## 2. 中翻英

```
把這篇中文部落格文章翻成自然的英文：{暫存夾}/draft-zh-final.md ，結果寫到 {暫存夾}/draft-en-agy.md（只寫這個檔）。

規則：
1. 段落數、順序、## 標題位置與中文一一對應；語氣是第一人稱、口語但正式、句子短，少術語。
2. 所有數字、百分比、日期、金額不得更改（日期保留同樣寫法；美元寫 US$X–Y）。
3. > 引用區塊是作者原話：翻成英文，並在每段引用的最後加一行 '> (translated from Chinese)'。
4. 程式碼區塊內的起手範本也翻成英文。
5. 圖片那幾行：alt 文字翻成英文，路徑把檔名的 .jpg 改成 -en.jpg（全部圖一致）。<video> 那行原樣保留。
6. 不新增觀點、比喻、總結句、emoji；不用 'not X but Y' 句型；結尾收束句照意翻。
7. 不要輸出 frontmatter。
寫完回覆一行 DONE。
```

## 3. 回來後的驗證（寫手自己做）

比對潤稿前後：數字集合（`re.findall(r'\d[\d,.]*%?')` 排序後相等）、`>` 引言／圖片／`<video>`／`##` 行相等、程式碼區塊相等；用 `diff <(sed 's/。/。\n/g' a) <(sed 's/。/。\n/g' b)` 逐句看 agy 加了什麼，贅語手動改回。
